# Image Grid Mask

This is a simple web application that allows you to upload an image, apply a customizable grid mask, and process the image with a pixelation effect.

## How to Use

1.  Open `index.html` in your web browser.
2.  Click the "Choose File" button to upload an image.
3.  Use the number input or the slider to adjust the number of grid cells. You will see a real-time preview of the grid on your image.
4.  Click the "Apply Mask" button to apply a pixelation effect to the image based on the grid.

## How to Deploy to GitHub Pages

1.  Push the `index.html`, `style.css`, and `script.js` files to a GitHub repository.
2.  In your repository's settings, go to the "Pages" section.
3.  Under "Source", select the branch you want to deploy from (e.g., `main`).
4.  Select `/ (root)` as the folder.
5.  Click "Save". Your site will be built and deployed to a URL like `https://<your-username>.github.io/<your-repository-name>/`.
